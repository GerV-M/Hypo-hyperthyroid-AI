# Локальный сайт для выявления заболеваний щитовидной железы на основе результатов анализов и данных пациента

Программа нацелена на выявление у пользователя гипотиреоза или гипертиреоза на основе предоставляемых лабораторных анализов гормонов и физических данных пациента.

## Инструкция
1. Скачайте файлы App.py и Program.py;
2. Установите все библиотеки при необходимости;
3. Запустите Program.py. Код автоматически скачивает все необходимые датасеты, выведет графики и обучит модели;
4. После завершения обучения последней модели и вывода графика сравнения метрик моделей перейдите в App.py. Запустите код, не обращая внимания на предупреждения;
5. Откройте терминал PowerShell. Выполните:
```PowerShell
streamlit run C:\***\App.py
```
Где вместо *** используйте путь к файлу на Вашем устройстве.

После выполнения команды Вас должно перенаправить в окно браузера, где пациент может ввести свои данные и получить предсказание на их основе.
Для большей прозрачности модели на сайте также отображён график наиболее важных для постановки диагноза признаков.
